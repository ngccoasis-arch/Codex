# Codex

A workspace for small app projects. The first planned project is **Text Reader / Read-Aloud Agent**.

## Text Reader

The reader accepts text the user posts in its own text-entry screen and speaks that text aloud. The user chooses a voice and playback speed. It does not interpret, summarize, rewrite, translate, or reply to the text.

Start with [the project overview](apps/text-reader/README.md), then read the [requirements and interaction decisions](apps/text-reader/docs/requirements.md) and [implementation roadmap](apps/text-reader/docs/roadmap.md).

**Status:** product foundation only. No runnable app or platform has been selected yet.
